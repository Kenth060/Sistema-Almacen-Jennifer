# Sistema de Control de Entradas y Salidas para el Almcen Comercial Jennifer

**Sistema web de gestión de inventarios, ventas y créditos comerciales.**

Proyecto académico desarrollado durante la carrera de Ingeniería en Computación, en la asignatura de Administración de Bases de Datos.

## Descripción

Sistema web desarrollado para apoyar la administración y el control de las operaciones de **Almacén Comercial Jennifer**, un establecimiento dedicado a la comercialización de ropa, calzado, artículos para el hogar, cosméticos y electrodomésticos.

El sistema tiene como objetivo facilitar la gestión de inventarios, ventas al contado y al crédito, compras, proveedores, clientes y personal, centralizando la información comercial en una base de datos.

También incorpora funcionalidades para el registro de abonos y el seguimiento de los créditos otorgados a los clientes.

## Funcionalidades principales

- **Gestión de inventario:** registro y administración de productos y existencias.
- **Control de ventas:** registro de ventas al contado y al crédito.
- **Gestión de créditos:** seguimiento de créditos comerciales y saldos pendientes.
- **Registro de abonos:** control de pagos realizados por los clientes.
- **Administración de clientes:** registro y consulta de información de clientes.
- **Gestión de proveedores:** administración de proveedores y compras.
- **Administración de personal:** registro y gestión de información del personal.
- **Generación de documentos:** elaboración de documentos y reportes mediante herramientas de generación de PDF.
